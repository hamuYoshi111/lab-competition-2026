# 実験の生データ

`../experiments.md` の表のもとになった、1 実験 1 ファイルの記録です。
各 JSON には、実験名・日時・説明・使った乱数の種・実行時の引数・ソースの SHA-256 と、
種ごとの評価値 E・各目的関数・コース・標準出力・世代履歴 CSV が入っています。
最後に 10 種ぶんの平均・標準偏差・最小・最大・平均時間の集計が付きます。

ファイル名の先頭の数字は作業の段階に対応します (00 が配布プログラムそのまま、
08 が提出設定での最終測定)。対応する報告書は `../03-speedup.md` 〜 `../08-final.md` です。
