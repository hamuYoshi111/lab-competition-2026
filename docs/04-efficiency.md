# 候補40地点への絞り込みで、同じ解を約30%短い時間で得た

既定にする候補として、候補絞り込みCのK=40、個体20・世代20を推奨する。平均総時間は0.174秒から0.122秒へ約30%短縮し、10種すべてで最終コースと全世代の評価値履歴が基準と一致した。今回は推奨だけを示し、`const.h` は変更していない。追加した実行時フラグもすべて既定でOFFである。

0.1秒未満を優先するなら、K=20、個体20・世代20が次の候補になる。総時間0.091秒に対し、E平均は0.00058から0.00082、標準偏差は0.000492から0.000611へ増えた。絶対値は小さいものの、平均で約41%、標準偏差で約24%の悪化があるため、「質を保つ」設定と区別して判断したい。

## 効いた変更と効かなかった変更

Aは、探索前と探索後の巡回順を記憶し、再登場したコースの探索を省く。今回のGA平均は0.147秒で基準の0.145秒とほぼ同じだった。113地点それぞれに2%の突然変異があるため完全一致が少なく、記憶・検索の費用を回収しにくいと推測する。ヒット率自体は計測していない。Eと履歴は全10種で一致した。

Bは、最初に改善した時点でその回の走査を終えるので、1回に調べる手は少なくなる。ただし小さな改善を重ねると反復が増え、別の局所解にも行き着く。今回はGA平均0.232秒、E平均0.00276・SD0.002222と両方が悪化したため採用しない。反復回数の増加は仕組みから考えられる理由であり、回数を実測した結論ではない。

Cでは、追加・置換で試す地点を減らすため、コース全体を評価する回数が減る。K=40はE・コース・履歴を保ち、K=20はさらに速い代わりにE平均とSDが増えた。近い地点だけでは時間調整に役立つ遠い地点も外すため、一般に同じ解を得る保証はない。

Dは世代ごとの20行を省き、最後のまとめと履歴CSVは残す。今回のパイプ出力では短縮を確認できず、E・コース・履歴は変わらなかった。実際のWindows画面への描画は測っていないので、画面表示がある場合の効果までは否定できない。

### 候補の選び方と時間の内訳

候補絞り込みのKは、位置の前後それぞれから選ぶ未選択地点数とした。両方の集合を合わせるため、1位置で最大2K地点を許可する。距離は各端点から候補への道のりで、正門も端点に含む。置換では取り除く地点の前後を使う。同距離なら候補番号の小さい順に選ぶ。

近い順のリストはGA開始時に一度作り、選択済みの地点を飛ばしてK地点ずつ取る。近傍を評価する順序は従来の候補番号順のままなので、Kが全候補以上なら従来の探索に戻る。削除・区間反転・1地点移動は引き続き全列挙する。

小数6桁の時間を別に保存した結果、世代ループの10種平均は基準0.134088秒、C(K=40)単独0.085750秒、C(K=20)単独0.056271秒だった。今回の主目的である世代ループを、それぞれ約36%、約58%短縮できた。近傍リストの作成費用はGA内の初期個体秒に含めており、総時間から除外していない。

AとDの小差は実行順を巡回させて再測定した。各設定は種1〜10を3周、計30回。小数6桁のGA平均はOFF=0.145998秒、A=0.145658秒、D=0.147664秒、A+D=0.145881秒だった。Aの約0.00034秒差は約0.23%にとどまり、安定した短縮効果とは判断しなかった。統計的な有意差の検定はしていない。[交互測定と再現性の記録](experiments/04-validation/verification.json) に全回の値を保存した。

このため `04e-combo` はC(K=40)だけをONとした。A・Dには明確な時間短縮がなく、Bは質も悪化した。K=20と40は同時にONにできないので、組み合わせと個体数・世代数の比較には、解を維持できたK=40を使った。

## 個体数・世代数の判断

5×5は平均Eが0.005を大きく超え、不採用。10×10の0.052秒は魅力があるが、平均とSDが基準の約3.7倍・3.5倍になる。10×20は0.076秒で、同程度の時間の20×10よりE平均・SDがよい。ただし10×20でも平均・SDは基準の約2倍なので、質をほぼ保つ推奨にはしなかった。

30×30・50×30はEが下がる一方、総時間が0.236秒・0.373秒に増える。今回の時間重視の方針では優先しない。まずC(K=40)・20×20を既定候補とし、時間短縮のためにどの程度のE悪化を許すかが決まれば、C(K=20)・20×20またはC(K=40)・10×20へ減らせる。参加者間の正規化に必要な他者の値はないため、合成得点の最適設定までは断定できない。

再現性は「同じ種・設定・ビルドなら同じ解」という意味で確認した。異なる種どうしのSDがゼロになるという意味ではなく、コンパイラーや環境をまたぐ一致は未検証である。
