# 参照解: 別実装のランダム再スタート付き局所探索でどこまで下がるか

C++ の GA が出す E が「そのデータで実際に届きうる値」に近いのかを知るために、C++ とは独立に書いた Python の局所探索 (`analysis/explore_data.py` の評価関数と探索手を再利用) を、同じ入力に対して合計 10,000 回の再スタートで走らせ、見つかった最良の E を参照値とした。

**この値は最適値の証明ではない**。十分多い回数の再スタートで到達できた最良値であり、より良い解が存在する可能性は残る。逆に、C++ の最小値がこの参照値とほぼ同じなら「探索は届くところまで届いており、届かない種があるだけ」と言える。

## 4. やり方と限界

手順は 2 段階。(1) 毎回 6〜12 地点と巡回順を無作為に選び、追加・削除・置換・区間反転 (2-opt) の全候補から E を最も下げる手を繰り返す。改善が止まったら次の開始点へ移る。これを 1000 回ぶんで 1 組とし、種を 1 ずつ変えて 10 組行う。(2) 各組の最良解に対し、上の 4 手に「1地点の移動 (Or-opt)」を加えた全近傍で、改善がなくなるまでさらに磨く (`polish`)。C++ の局所探索と同じ手の範囲までそろえるため。候補の絞り込み (K=40) は行わず、毎回すべての候補を調べている。

**限界**: これは最適値の証明ではない。10 組それぞれが独立に同じ値へ収束していても、その外に良い解が無いことは示せない。また Python 側は GA を持たないので、解の組み替え (交叉) で初めて届く解は原理的に見つけられない。

再現コマンドは `python analysis/reference_search.py --all --restarts 1000 --chunks 10 --report`。生データは `analysis/reference_cache/<データ名>.json`。
