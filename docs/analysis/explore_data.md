## 道のりと累積登りの行列

正門と全候補を並べた 114×114 行列を計算しました。異なる道路ノードは 92 個で、同じノードからの計算は共有しています。同じ道路ノードを使う候補も別の候補として集計するため、異なる候補間でも距離が0になります。

| 集計対象 | 距離 最小 / 中央値 / 最大 (m) | 登り 最小 / 中央値 / 最大 (m) | 解釈 |
| --- | --- | --- | --- |
| 正門＋候補、対角を除く | 0.000000 / 1244.065914 / 3037.301009 | 0.000000 / 18.700000 / 86.700000 | 出発点と目的地の順序を区別し、往路と復路を別々に数えます。 |
| 候補間のみ、対角を除く | 0.000000 / 1251.927797 / 3037.301009 | 0.000000 / 18.700000 / 86.700000 | 正門を除き、候補同士を移動する区間の分布です。 |

正門を含む対角以外の組は 12882 組、到達不能は 0 組です。到達不能は分布から除外し、対角の距離・登りはともに0です。登りの値は距離最短の経路で測ったもので、登りを最小化した値ではありません。
